Aether Enums is developed in the open at [UAMS-Web/aether-enums](https://github.com/UAMS-Web/aether-enums). These pages are the source of the wiki: edit them in `docs/wiki/` through a pull request, because the wiki is rebuilt from that folder when a release is published and edits made in the wiki are overwritten.

- [Report a problem](https://github.com/UAMS-Web/aether-enums/issues): search the open and closed issues first. Known problems and their fixes are in [Troubleshooting](Troubleshooting.md).
- [Releases](https://github.com/UAMS-Web/aether-enums/releases): the changelog for each version.
- [Contributing](https://github.com/UAMS-Web/aether-enums/blob/main/CONTRIBUTING.md): the path from an issue to a merged pull request.
- [Development loop](https://github.com/UAMS-Web/aether-enums/blob/main/docs/DEVELOPMENT.md): running the add-on in a Statamic host.
